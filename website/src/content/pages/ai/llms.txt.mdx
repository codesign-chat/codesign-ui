## What is LLMs.txt?

We support [LLMs.txt](https://llmstxt.org/) files for making the Codesign UI documentation available to large language
models (LLMs). This feature helps AI tools better understand our component library, its APIs, and usage patterns.

## Available Routes

We provide several LLMs.txt routes to help AI tools access our documentation:

- [llms.txt](https://codesign.chat/llms.txt) - Contains a structured overview of all components and their documentation
  links
- [llms-react.txt](https://codesign.chat/llms-react.txt) - React-specific documentation and implementation details
- [llms-solid.txt](https://codesign.chat/llms-solid.txt) - SolidJS-specific documentation and implementation details
- [llms-vue.txt](https://codesign.chat/llms-vue.txt) - Vue-specific documentation and implementation details
- [llms-svelte.txt](https://codesign.chat/llms-svelte.txt) - Svelte-specific documentation and implementation details

## Usage with AI Tools

### Cursor

Use the `@Docs` feature in Cursor to include the LLMs.txt files in your project. This helps Cursor provide more accurate
code suggestions and documentation for Codesign UI components.

[Read more about @Docs in Cursor](https://docs.cursor.com/context/@-symbols/@-docs)

### Windstatic

Reference the LLMs.txt files using `@` or in your `.windsurfrules` files to enhance Windstatic's understanding of
Codesign UI components.

[Read more about Windstatic Memories](https://docs.codeium.com/windsurf/memories#memories-and-rules)

### Other AI Tools

Any AI tool that supports LLMs.txt can use these routes to better understand Codesign UI. Simply point your tool to any
of the routes above based on your framework of choice.
